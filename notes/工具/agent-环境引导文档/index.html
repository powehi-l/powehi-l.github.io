    Agent 环境引导文档

    Agent 环境引导：自动安装 Skill、工具并集成

    Section titled “Agent 环境引导：自动安装 Skill、工具并集成”

    适用对象：一个全新的、空白的 Agent（没有预置任何 skill/工具）。 目标：让这个 Agent 根据本文档，自动完成以下 Skill 和相关工具的安装、本地环境集成，并建立“遇到任务→知道该用什么工具/skill”的识别能力。 执行方式：Agent 逐节执行命令，全部完成后 self-check 验证。

    0. 前置准备与总览

    Section titled “0. 前置准备与总览”

    本引导会安装 4 个 Skill 和 2 个工具链（ffmpeg + markitdown），并做环境集成。

    类别 名称 用途
    Skill find-skills 发现/安装开源 skill（npx skills）
    Skill ponytail 极简编码：stdlib 优先、YAGNI
    Skill i-have-adhd ADHD 友好输出，防答案被埋没
    Skill karpathy-guidelines 减少 LLM 编码失误的行为准则
    Skill ffmpeg-video-editor FFmpeg 视频/音频编辑命令库
    工具 ffmpeg + ffprobe 命令行视频/音频剪辑、调色、转码
    工具 markitdown 文档→Markdown（供 LLM 读取）

    关键机制说明（务必先读）：

    • 每个 Skill 的本质是一个 SKILL.md 文件，安装到 Agent 的 skills 目录后，Agent 在各种会话中会自动加载并遵循其规则。
    • most critical：Skill 的 SKILL.md 前置元数据里，description 字段必须 ≤ 60 字符（系统提示词索引预算）。任何实际 skill 的原始 description 都远超此限，必须精简为一句、以触发器开头、以句号结尾。描述超长会被创建工具直接拒绝，而非截断。
    • 多个 skill 需要随附脚本/参考文件（scripts/references/assets），要把它们一并装入 skill 目录以保持自包含。

    1. 安装 Skill：通用流程

    Section titled “1. 安装 Skill：通用流程”

    对下面每一个 Skill：

    1. 用 git clone --depth 1 把源仓库克隆到临时目录（保证拿到完整、未截断的 SKILL.md）
    2. 读取完整 SKILL.md
    3. 重写 description 为 ≤60 字符（触发器优先 + 句号）
    4. 用技能创建工具 skill_manage 的 create 动作创建（精简描述 + 完整正文）
    5. 用 write_file 装入随附的 scripts/references/assets
    6. 用 skill_view 验证 readiness_status: available
    7. 清理临时目录

    2.5 ffmpeg-video-editor

    Section titled “2.5 ffmpeg-video-editor”
    • 源：https://github.com/bryanwhl/ffmpeg-video-editor，raw：https://raw.githubusercontent.com/bryanwhl/ffmpeg-video-editor/main/SKILL.md（在仓库根目录，不在 skills/ 子目录）
    • 精简 description：FFmpeg video/audio editing commands and workflows.
    • 正文：完整内容（Probe、Trim、Transcode、Concatenate、Overlay、Transitions、Color Grading 等全部命令）。
    • 随附文件（务必装入 skills 目录）：
      • scripts/probe.sh → https://raw.githubusercontent.com/bryanwhl/ffmpeg-video-editor/main/scripts/probe.sh
      • scripts/concat.sh → .../scripts/concat.sh
      • scripts/normalize-audio.sh → .../scripts/normalize-audio.sh
    • 验证：ffmpeg -version 存在（工具前置），脚本在用时 chmod +x。

    4. 环境集成

    Section titled “4. 环境集成”
    1. 确认 skills 目录存在：~/.hermes/skills/（或 $HERMES_HOME/skills/）。若无则创建。
    2. 验证全部 skill 可加载：逐个 skill_view(<name>)，确认 readiness_status: available。
    3. 可选：把 ffmpeg-video-editor 的脚本设为可执行（chmod +x），以便直接调用 concat.sh 等。
    4. 确认工具在 PATH：which ffmpeg ffprobe、markitdown 的 venv activate 方式记录清楚，方便以后调用。

    5. 建立“任务 → 工具/Skill”识别映射

    Section titled “5. 建立“任务 → 工具/Skill”识别映射”

    Agent 遇到任务时，按下表判断该加载/调用什么：

    用户需求（触发词） 使用
    “剪辑/裁剪/转码/压缩视频”、“把视频变小”、“加字幕/水印” ffmpeg-video-editor skill + ffmpeg
    “查找有没有 XX 的 skill/插件”、“装个 skill” find-skills skill
    “写简洁点”、“别过度设计”、“最简方案” ponytail skill
    “直接给答案”、“别啰嗦”、“重点是什么” i-have-adhd skill
    “写/改代码”、“注意质量”、“别乱改无关代码” karpathy-guidelines skill
    “把 PDF/Word/Excel 转成文本/markdown” markitdown 工具

    Self-check（完成后自答）：

    • 5 个 skill 都在 skills 目录，skill_view 显示 available
    • ffmpeg -version、ffprobe 可用
    • markitdown 可导入/运行
    • 每个 skill 的 description 均 ≤60 字符
    • 会话中被用户要求“剪辑视频”“写最简代码”“找 skill”时，能正确调起对应能力

    维护说明：本表与“好用 Skill 合集”知识库文档保持一致。新增 skill 时，若装有 installing-skills 引导 skill，优先参考其过程（定位 SKILL.md、精简 description、装随附文件、live-check stars）。
