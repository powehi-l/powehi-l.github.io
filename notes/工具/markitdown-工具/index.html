      MarkItDown 工具

      MarkItDown（微软官方 · AI 文档转 Markdown 工具）

      Section titled “MarkItDown（微软官方 · AI 文档转 Markdown 工具）”

      一个把各种文件/文档转成 Markdown 的命令行工具，专为 LLM 和文本分析管线设计。

      基本信息

      Section titled “基本信息”
      • 项目：microsoft/markitdown（Microsoft 官方）
      • GitHub Star：≈ 186k（2026-09 实时）
      • 语言：Python（需 3.10+）
      • 定位：轻量级文档→Markdown 转换器，重点保留文档结构（标题、列表、表格、链接），供 LLM 读取。

      主要作用

      Section titled “主要作用”

      把任意常见文件转成 Markdown，让 LLM 能直接“读懂”各类文档。它比通用工具更侧重结构保真，输出 token 高效。

      支持转换的格式

      Section titled “支持转换的格式”
      • PDF
      • PowerPoint（PPT）
      • Word
      • Excel
      • 图片（EXIF 元数据 + OCR 文字识别）
      • 音频（EXIF 元数据 + 语音转写）
      • HTML
      • 文本类（CSV / JSON / XML）
      • ZIP（遍历内部内容）
      • YouTube URL
      • EPUB 电子书
      • ……以及更多

      适合我的场景

      Section titled “适合我的场景”
      • 把收到的论文 PDF、Word、Excel 转成 Markdown，方便我阅读/总结/入知识库
      • 音频语音转写后进入文本管线
      • 网页/HTML 转 Markdown 便于整理

      ⚠️ 安全提醒（官方重点标注）

      Section titled “⚠️ 安全提醒（官方重点标注）”

      MarkItDown 以当前进程权限访问资源（类似 open() 或 requests.get()）。在不可信环境下要注意输入清洗，尽量调用最窄范围的 convert 函数（如 convert_stream() / convert_local()），不要处理来源不可信的文件。
